TurboTune Tools

The Ultimate Android System Tuner & Performance Optimizer (No Root Required)

TurboTune Tools is a powerful system utility designed for Android enthusiasts. By leveraging the power of Shizuku, it provides deep system-level customization, performance tuning, and privacy controls without needing root access.

---

Core Features

1. One-Tap Optimization (Home)

· Optimize Now: Instantly flush RAM and trim system caches with a single tap.
· Real-time Measurement: Displays exactly how much RAM (MB/%) and Storage (MB/%) were successfully freed.
· Target App Selection: Easily search and select any user-installed app to apply specific tweaks.

2. Tuning Console

· FPS Boost: Unlocks high framework configurations and stabilizes frame rates system-wide.
· GPU Performance: (For Games Only) Slightly reduces rendering resolution (0.95 downscale) to boost FPS without losing visual quality.
· UNLOCK FPS: Locks the display refresh rate to your preferred level (60Hz, 90Hz, or 120Hz) with animated visual feedback.

3. AppOps Controls (Privacy & Background Restrictions)

Take back control of your privacy. Block specific permissions for any user-installed app:

· Background Activity
· Location Access
· Camera Access
· Microphone Access
· Notification Access
· Data Access (Wake Locks)

4. System Tweaks & Compilation

· Extreme Mode: Applies a system-wide CPU/GPU performance policy for maximum responsiveness.
· BG-DEXOPT JOB: Recompiles background app code system-wide for smoother overall performance.
· Wi-Fi Scan: Disables background Wi-Fi scanning to save battery.
· App Compile (Optimize): Recompiles specific apps based on usage profiles for faster launch times, with the ability to reset changes.

5. System Stats & Process Manager

· Live RAM Monitor: Visualizes the top 5 RAM-consuming apps in real-time.
· Process Killer: Safely force-stop background apps to free up system resources (with built-in system app protection).

6. Settings & Recovery

· Permission Manager: Easily fix missing permissions (Shizuku, Write Settings, Battery Optimization) with one tap.
· Danger Zone: Restore all system defaults and undo all tweaks applied by the app.

---

Prerequisites

· Android Version: Optimized for Android 12 up to Android 15/16. (Works on Android 10/11, but performance may be limited).
· Shizuku: Required for executing shell commands. No root required.
· Permissions: Overlay, Battery Optimization Exemption, and Write Settings.

Safety & Disclaimer

· No Data Collection: All settings and data remain strictly on your device. No ads, no telemetry.
· Use with Caution: This app executes system-level shell commands. While built with safety filters, the developer is not responsible for any system instability, battery drain, or damages caused by user mistakes.
· Protected System Apps: TurboTune Tools automatically blocks the termination of core system apps to prevent device crashes.
